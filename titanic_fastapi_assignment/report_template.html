Observations

1. How does Online Inference differ from Batch Inference?

Online inference returns a prediction for one request or record at a time, which is useful when an individual result is needed immediately. Batch inference submits many records together and returns their predictions in one operation, making repeated or scheduled workloads more efficient.

2. What is the difference between Streaming Inference and Batch Inference?

Streaming inference consumes arriving records incrementally and produces a result for each record as it arrives. Batch inference waits until a fixed group has been collected, then processes that group together. This project simulates a stream by handling ten held-out passengers sequentially with a one-second interval.

3. Why is FastAPI used for model serving?

FastAPI exposes the trained pipeline through standard HTTP endpoints, provides request validation with Pydantic, and automatically documents and tests the API through Swagger UI at /docs. This lets another application request predictions without importing or retraining the model itself.

4. Why should the same trained model be reused for all inference strategies?

Reusing one saved pipeline keeps preprocessing and learned parameters consistent across online, batch, streaming, and API predictions. It makes results comparable, avoids unnecessary retraining, and reduces the risk that different code paths use mismatched transformations or model versions.

Evaluation and data handling. The complete preprocessing-and-classification pipeline was fit once using a stratified 80/20 split of the official Kaggle Titanic train.csv. Accuracy is measured only on the 20% held-out test split. The 31 demonstration records are drawn from that held-out split, are disjoint across strategies, and are passed to inference without the outcome label. The Kaggle source data is not redistributed in this package.
Dataset source: Kaggle, “Titanic - Machine Learning from Disaster,” official competition data page. Metric: accuracy = correct held-out predictions / held-out records.
